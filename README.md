# Открытка ко Дню отца и Дню матери в Якутии

Интерактивная веб-открытка к третьему воскресенью октября: в этот день
по всей России отмечают День отца, а в Якутии — День матери.

Мать и отец стоят каждый на своей половине. По касанию они сходятся к
шву, фиолетовый растекается от шва к обоим краям, и проступает общая
семья с оберегом. Обе половины движутся зеркально: ни одна не главнее.

Рисунки, обереги (харысхал) и надписи на якутском — авторские. Они
вынуты из макета векторами и не изменены: обереги не поворачиваются и
не перекрашиваются.

## Запуск

```bash
npm install
npm run dev
```

Открытка откроется на http://localhost:3000.

Стек: Next.js 16, React 19, GSAP.
